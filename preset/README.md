# 学习模式 —— DSH「学习模式」agent 预设（learning-loop）

「学习模式」是 [dsh-learning-space](../README.md) 仓库三件套里的第一件：给 DSH 会话换上一个「专属导师」身份，让它能带你走完「测评 → 教材 → 测验 → 过关/重讲 → 知识库」的完整学习闭环。

本目录是它的安装源：装好后，新开会话时模式选择器里就会出现「学习模式」。

## 学习闭环是怎么走的

- **基线测评**：先做一份摸底测验，导师据此调整难度；
- **生成课程**：总目录 + 章节教材（HTML，带交互演示）+ 六种题型的测验；
- **硬门槛**：合并正确率 ≥80% 才过关；没过就**换个讲法重讲**（最多重讲 3 版）；
- **每章知识库**：过关后导师写一篇小结，记录你哪里稳、哪里虚，指导下一章怎么讲；
- **断点续学**：工作区里有个 `meta.json`，中断后回来接着学，不从头再来。

## 安装

学习模式有两种装法，任选其一（完整步骤见[仓库 README](../README.md)）：

- **一键脚本（推荐）**：克隆仓库后运行 `install.ps1`，三个部分一次装齐；
- **手动拷贝**：把本目录内容拷到 `%USERPROFILE%\.dsh\.agent-presets\learning`（macOS/Linux 为 `~/.dsh/.agent-presets/learning`）。

装好后**新开一个会话**，模式选择器就会出现「学习模式」（已开着的会话不会变）。

> 如果你之前装过旧版 ZCode 的 learning-loop 技能，本模式会自动覆盖它，不会冲突。

## 使用

1. 新开会话，选「学习模式」；
2. 直接说「我想学 X」，或使用命令：
   - `/learning-loop` —— 有课续课，没课问你学什么；
   - `/learning-loop React` —— 跳过提问直接以 React 开始（仍会问你的目标水平）；
   - `/learning-loop status` —— 查看所有课程进度，只读不改文件；
   - `/learning-loop upgrade` —— 给旧课程打个版本标记后继续学；
3. 学习材料永远生成在**当前工作目录**下的 `<主题>-learning/`（或 `<主题>-学习/`）文件夹里，不会动你的其他文件。

## 目录和文件名会按你的语言自动命名

| 逻辑（英文） | 中文用户看到的 |
|---|---|
| `00-baseline`（基线测评） | `00-基线测评` |
| `plan` / `chapters` / `quizzes` / `wiki` / `notes` | `计划` / `章节` / `测验` / `知识库` / `笔记` |
| `stage1-ch01-intro.html` | `阶段1-章01-入门.html` |
| `stage1-ch01-quiz.html` | `阶段1-章01-测验.html` |

几条不变的规定：状态文件始终叫 `meta.json`；主题名始终是英文小写（`react`、`intro`）；版本号（`_v2` 等）和数字不翻译。详细规则见 `skills/learning-loop/references/naming.md`。

## 升级

重跑仓库的 `install.ps1`（幂等，可重复），或手动重新拷贝本目录覆盖即可。升级后新开一个会话生效。

## 目录结构

```
.
├── preset.yml                  # 模式名称与简介（模式选择器里显示的内容）
├── agent.cordis.yml            # 导师身份 + 工具 + 技能发现配置
└── skills/
    └── learning-loop/
        ├── SKILL.md            # 学习闭环主流程
        └── references/         # 模板、题型、评分、命名等 11 份规则
```

## 小提示

- 本模式是官方 `standard` 预设的精简版：去掉了计划模式、上下文压缩、目标管理等用不到的部分，需要时可以自行补回。
- 为了让导师能查官方文档做课程研究，本模式放宽了网页抓取权限（只读抓取，不会自动提交任何表单）。
